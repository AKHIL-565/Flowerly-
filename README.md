# 🌸 Flowerly - Luxury Floral Boutique & Delivery

A modern, fullstack e-commerce web application for premium handcrafted flowers and bouquets, built with **Next.js 14**, **React**, **Tailwind CSS**, and **TypeScript**.

---

## ✨ Features

- **Luxury Floral Boutique Design**: Editorial two-column hero, responsive mobile navigation, and pastel flower cutouts.
- **Shop Catalog & Smart Filters**: Filter across 50 floral arrangements by Category, Occasion, Price, Delivery Speed (Same-Day / Express / Midnight), and Arrangement style.
- **Product Details & Verified Reviews**: High-res floral photography, size/stem selector, delivery availability check, and customer review submission.
- **Cart & Dynamic Coupons**: Real-time cart calculations in ₹ (INR) with coupon code validation (`FLOWER10`, `LOVE15`, `FREESHIP`).
- **Express Checkout**: Recipient address form, time slot selection, custom handwritten greeting card message, and multiple payment methods.
- **Live Order Tracking**: Real-time 4-step progress tracker (`/orders`) by Order ID or tracking code.
- **Local Persistence & APIs**: File-based JSON database engine for orders, reviews, and user sessions.

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/Flowerly.git
cd Flowerly
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
